# 🚗 Fleet Management System

A comprehensive fleet management system built with Django that helps manage vehicle servicing operations through three different user roles: Admin, Mechanic, and Customer.

## Features

### Admin Dashboard

- Manage mechanics (approve/disapprove, view details)
- Handle service requests
- Track vehicle service status
- View/manage customer details
- Monitor mechanic attendance
- View customer feedback
- Generate service reports

### Mechanic Features

- Personal profile management
- View assigned service requests
- Update service status
- Mark attendance
- Track service history
- Update vehicle repair costs

### Customer Features

- Book vehicle service requests
- Track service status
- View service history
- Submit feedback
- Update profile information
- Multiple vehicle management

## Technology Stack

- **Backend:** Django 3.0
- **Frontend:** HTML, CSS, JavaScript, Bootstrap
- **Database:** SQLite3
- **Additional:** Font Awesome, jQuery

## 🔄 Service Request Flow

1. **Customer** creates a service request.
2. **Admin** assigns a mechanic.
3. **Mechanic** updates the service status.
4. **Customer** check the completion.
5. **Service completion** and feedback submission.
